# AI assistance, tools and services (disclosure)

This file is kept up to date as the project grows.

## AI assistance used while building

- **Claude (Anthropic)** is used as a coding and planning assistant: it helped plan the structure and write and explain code. The team runs, tests, reviews and understands the code, and is responsible for it.
- **ChatGPT (OpenAI)** was used before the event window only to explore screen ideas for the interface. **No code from that exploration is used in this repository**; all code here was written during the event window.
- Other products' screenshots (for example compliance and approval tools) were looked at only as inspiration for what information to show. No designs or code were copied.

## AI used inside the product

- **Google Gemini API (free tier)**: planned for claim analysis and suggested wording. Not connected yet. Only fictional sample data is ever sent to it. Free-tier data may be used by the provider to improve its products, so no confidential data is sent.
- The AI never publishes, approves or edits anything on its own. Findings without a valid cited source are shown as "Needs human check".

## Libraries and services

- Frontend: React, Vite, Tailwind CSS, React Router, Supabase JS client, Lucide icons.
- Review service: Python, FastAPI, Uvicorn, httpx, python-dotenv.
- Database and login: Supabase (PostgreSQL, Auth).
- Hosting (free tiers): Vercel, Render, Supabase. Uptime pings: a free monitoring service.
